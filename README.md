# Laboratorio C

Laboratorio interactivo para aprender C desde cero (lección 1: fundamentos).

**Úsalo aquí:** https://cesarmingueza0-byte.github.io/laboratorio-c/

- **Rayos X**: pulsa cualquier pieza de un programa y te explica qué es y por qué está ahí.
- **Taller**: mini-compilador con errores explicados en español y la memoria dibujada.
- **Retos**: 7 ejercicios que se corrigen solos.
- **Chuleta**: todo lo básico en una página.

En el móvil puedes instalarla como app (menú del navegador → "Añadir a pantalla de inicio") y funciona sin conexión.

> El Taller es un simulador de la lección 1, no un compilador de C completo. Para los ejercicios de clase usa GCC.
